# El rescate de Marta

Práctica realizada en Delightex Edu para la asignatura
Realidad y Accesibilidad Aumentadas.

**Autor:** Víctor Lasheras

## Descripción

El rescate de Marta es una aventura narrativa en primera persona en la
que el jugador deberá investigar la desaparición de Marta siguiendo
diferentes pistas por el pueblo.

La historia lleva al jugador por diferentes escenarios, incluyendo el
pueblo, la casa de la abuela, un bar, una granja y una casa abandonada.

El proyecto utiliza CoBlocks para implementar diálogos, interacciones,
movimientos, sonidos, animaciones, cambios de escena, variables y
acontecimientos narrativos.
